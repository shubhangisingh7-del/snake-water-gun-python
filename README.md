#  Snake Water Gun Game

A simple Snake-Water-Gun game built using Python.

## Features
- User vs Computer
- Random computer choice
- Winner detection
- Easy-to-understand code

## Technologies Used
- Python 3

## How to Run

```bash
python snake_water_gun.py
```

## Game Rules
- Snake drinks Water  
- Water damages Gun
- Gun kills Snake
